# Changelog

The English changelog is authoritative; `CHANGELOG.zh-CN.md` mirrors it.

## [Unreleased]

### Added

- Add an independent Attempt-scoped `generation` component with the namespaced
  `generation-delegate` capability and required single WorkPlan generation
  service and a separate prepared query dependency. The external capability
  requests those ProjectService permissions;
  the package permission union grows while the original knowledge query/check
  permissions, contracts and scopes remain unchanged. Forward one fixed child
  identity/source subset and preserve original success, failure or unknown
  receipt/error bytes using pinned SDK validators, without prompts, model access,
  retries or completion claims. Receipts acknowledge child enqueueing; later
  model/credential failures remain child outcomes. This stays in the same
  undistributed alpha.1 batch and requires separate review of the new bytes and
  permission, without replacing an installed same-version snapshot automatically.

### Changed

- Replace the generation delegate's old input with the bounded SDK component
  wrapper and a separately declared, prepared terminology-query dependency.
  Advance that capability to schema/behavior **2/2**; Core service schemas remain
  **1/1**. Complete one exact lookup before submitting the unchanged Core child; preserve
  empty matches, query failure/unknown, transport and cancellation semantics.
  References remain unadopted and do not override model prompts. New package
  bytes and permission need explicit review in the same undistributed alpha.1
  batch; earlier SDK archives and installed snapshots remain intact.

- Register the exact callable roster through the public `contributions` and
  `register(id, handler)` API. Setup and shutdown use Process-3 component
  identity; default Project scope and domain behavior remain unchanged.

- Prepare the public validators and package provenance from the selected
  Process-3 SDK snapshot for a matching Host. Query/text-review contracts and
  the same undistributed alpha.1 package version remain unchanged.

- Replace the custom check input/output with the public SDK text-review input
  and report contracts. The existing check capability advances to 2/2; query
  contracts remain 1/1, and the unreleased package remains `0.1.0-alpha.1`.
  Generate four advisory concept rules and their titles/descriptions from the
  original terminology resource. Require an explicit rule subset for each
  invocation, exact Host provider and Resource pins, complete outcomes and
  UTF-16 diagnostics. Missing translations retain captured NA or unavailable
  status; oversized reports fail without truncation. Findings remain unadopted
  suggestions. Core current-QA composition/adoption remains pending; the prior
  custom check shape has no compatibility fallback.

- Generate the bounded public text-query presentation from the original terminology resource, with exact input pins, explicit target/sense options and reference columns. Single and batch consumers use the SDK helper and the original component; rendered product and Agent integration remain pending.

- Replace the package-specific Agent descriptor with the public SDK's strict
  read-only tool selector, exact profile and same-package terminology/Skill
  references. Preparation validates its structure from the pinned SDK artifact;
  capability contracts, limits and permissions remain owned by the original query.

- Add an original, pinned philosophy terminology resource with shared public
  query and deterministic check capabilities, explicit sense and locale scope,
  complete query basis and UTF-16 diagnostics.
- Provide a Skill and Agent tool descriptor selecting the same query capability.
  Product editor, batch and Agent integration remains pending.
