# SMAPI package boundary

Logical plugin ID: `stardew-smapi`.

This directory owns the future independent SMAPI package: discovery and material
preflight, source extraction, existing translation import, identity/matching,
format checks, building and artifact verification. The current domain
implementation has not moved from Tsumugi yet; this directory supplies no worker
or executable capability. A version and changelog will describe the actual first
package, with recorded source provenance and public SDK compatibility.
