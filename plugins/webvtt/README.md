# WebVTT package boundary

Logical plugin ID: `webvtt`; supported domain target: `webvtt-captions` profile `1`.

This directory owns the future independent caption package: parsing,
cue identity/timing/layout, payload checks, preservation-oriented output and
artifact verification. The current domain implementation has not moved from
Tsumugi yet; this directory supplies no worker or executable capability.
Translation import is not part of the existing supported profile. A version and
changelog will describe the actual first package and its source provenance.
